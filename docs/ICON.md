# App icon

The Broschy icon was created for this project with the built-in image generation tool. A translucent teal lowercase b sits on a pale silver app tile. Native macOS tools convert the PNG into ICNS representations from 16 to 1024 pixels.

Source: `Resources/AppIcon.png`

Bundle: `Resources/Broschy.icns`

## Generation prompt

```text
Create a polished macOS application icon: a simple sculptural lowercase b made of frosted teal glass, centered on a pale silver sea-glass rounded-square tile. Premium restrained 3D material, broad clean silhouette, single generous circular counter, subtle cyan rim lighting, front-facing orthographic. Square 1024px PNG. The tile is inset by 8% on all sides with smooth superellipse corners. The area outside the tile is completely transparent alpha, clean cutout with no stray flecks or particles. Do not depict transparency as a checkerboard or as a colored background. No text except the lowercase b symbol, no additional objects, no heavy shadows. A quiet sophisticated native application icon readable at 32px.
```
